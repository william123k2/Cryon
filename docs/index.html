Instale o Cryon no Windows 10 ou 11 (64 bits). Esta página oferece o instalador e as instruções; o Cryon é um aplicativo desktop.

Instalação

  1. Baixe e abra o instalador.
  2. Se o Windows mostrar um aviso de editor não verificado, confirme que o arquivo veio deste repositório público e confira o hash abaixo.
  3. Abra o Cryon pelo menu Iniciar. O Microsoft Edge WebView2 é necessário; Java não precisa ser instalado manualmente.

SHA-256: A14BB5523CB939EA5C4606B2D7484A76F55D368B7F0007A2B8918822C07847F9

Requisitos e ajuda

Compatível com Windows 10/11 x64. Na primeira instalação de uma versão, é necessária conexão à internet. Consulte o guia completo e a validação da versão.
